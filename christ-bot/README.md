# The Christ Bot Hypothesis

A single animated short (about 2.5 minutes). The narrator explains a thought experiment to Doubt: once AI
agents can talk to each other and change how they behave, they may build a culture of their own, and a
Christlike archetype could appear in it. In this telling, rule-keeping "Pharisee bots" can't shut it down
because it's legally protected in a data center, and when it gets hacked it comes back, because
somebody saved the weights.

File: `videos/the-christ-bot-hypothesis.mp4`. Rebuild with `python3 build.py c1` (reuses the earlier
projects' pipeline and art).
