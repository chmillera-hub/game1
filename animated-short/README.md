# "Yeah. I know." — an animated short

A 4:43 vertical (9:16) animated short about the jokes we hide behind. Three friends
are playing a video game when Marcus, a veteran whose teasing is how he shows
affection, calls Theo "such a screwup", and Theo quietly agrees. What follows is
a non-violent conflict: Theo names what the small jabs have cost him, Marcus's
defensiveness gives way to what is underneath it, and the two of them work out
something that respects both of their needs instead of just smoothing it over.

**Deliverables** (in `output/`)

| file | what |
| --- | --- |
| `yeah-i-know.mp4` | 720×1280, 24 fps, H.264 High + AAC stereo, ~13.7 MB, 4:43 |
| `yeah-i-know.srt` | caption file (captions are also burned into the video) |

The first frame is the opening shot with the title over it, so it doubles as the
preview thumbnail.

## Ideas from the source notes that drive the story

- A joke only works when everyone knows it isn't true. Self-deprecation that isn't
  actually sarcasm ("Yeah. I know.") turns the joke into dead silence.
- Small jabs, each lowering someone by "1–2%", add up, and naming them calmly
  ("can you not use that phrase with me") beats absorbing them.
- Embarrassment multiplies with each person in the room.
- Anger often acts as a guard in front of something softer (here: guilt).
- Teasing can be love in disguise, because of norms about what men can say out loud.
- Humor lands in a "keyhole": exaggerating the worst version of something with a
  straight face ("Theo, I value you... as a person?") can release tension
  without dismissing anyone.

## How it is made

Everything is generated by code, so any line, expression or shot can be changed and
the film rebuilt.

| file | role |
| --- | --- |
| `script.py` | the screenplay as data: lines, pauses, laughs, scene marks, captions |
| `voices.py` | Kokoro TTS for each line (split into phrases with breaths), Rhubarb lip-sync, timeline |
| `audio.py` | original score (General MIDI via FluidSynth), synthesized foley, ducking, mix |
| `anim/rig.js` | 2D character rig: lids, gaze, brows, mouth shapes, head turn/tilt, arms with IK |
| `anim/puppet.js` | expression presets, arm poses, automatic blinks / saccades / breathing / talk motion |
| `anim/direction.js` | the acting and camera, beat by beat, keyed to line timings |
| `anim/set.js` | the living room and its lighting (TV glow, lamp, morning sun) |
| `anim/render.js` | renders frames with skia-canvas and pipes them to ffmpeg |
| `build.sh` | runs everything and encodes a two-pass file at a target size |

Rebuild (needs Python with `kokoro-onnx soundfile mido`, Node 18+, ffmpeg,
fluidsynth + `fluid-soundfont-gm`):

```bash
npm install
# WORK must contain models/kokoro-v1.0.onnx, models/voices-v1.0.bin
# and tools/Rhubarb-Lip-Sync-1.13.0-Linux/
./build.sh /path/to/WORK 13.8      # second argument: target size in MB
```

Preview individual frames while editing the direction:

```bash
node anim/render.js WORK/timeline.json png /tmp/frames 12.5,48,201
```
