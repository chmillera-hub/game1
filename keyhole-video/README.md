# The Keyhole

A 3:44 portrait (720×1280, 24 fps) animated short adapted from the "humor" notes:
laughter as love squeezing past a rule, the "too real" joke, social alchemy,
and humor as the back door into the fortress where emotions get locked away.

| File | Notes |
| --- | --- |
| `The_Keyhole.mp4` | Burned-in captions. 13.4 MB, H.264 + AAC, −16 LUFS |
| `The_Keyhole_no_captions.mp4` | Same cut without captions, for platforms that auto-caption |

Frame 0 is the title card over the classroom, so social previews aren't black.

## Story beats

1. **Classroom**: "Not. One. Sound." Two kids lock eyes and lose it. Narration: a laugh is love squeezing through a keyhole.
2. **Backyard, 20 years later**: Danny (two tours) jokes "you're a piece of [bleep]". Tired, the narrator forgets to exaggerate: "Yeah. I guess I am." Dead silence.
3. **Inside the narrator's head**: Embarrassment panics ("three people, that's like *triple*"), Doubt deadpans, Anger offers to handle it, Boredom says "flip it".
4. **Social alchemy**: "I'm a piece of [bleep] with *you* pieces of [bleep]…" Everyone cracks up.
5. **Porch, later**: "That one stung." Danny: "Over there, if you didn't laugh at it… you had to feel it."
6. **Inside Danny's head**: Anger was never locked up. Anger was the guard, and Guilt was behind the door. The laugh opens it.
7. **Resolution**: "Okay. Deal." / "I'm *your* piece of [bleep]." The camera pans up to a keyhole made of stars.

## Rebuilding

Everything is generated by code: Kokoro TTS voices with phoneme-timed lip sync, synthesized music, sound effects and laughter, and Skia vector rendering.

```bash
pip install kokoro-onnx soundfile skia-python scipy   # plus ffmpeg on PATH
# model files go in keyhole-video/tts/ (next to src/):
#   kokoro-v1.0.onnx, voices-v1.0.bin  (github.com/thewh1teagle/kokoro-onnx releases)
#   kokoro-timed.onnx = onnx/model.onnx from huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX-timestamped
cd src
python3 build_audio.py            # voices, timing, music, mix -> build/
ffmpeg -i build/mix.wav -af loudnorm=I=-15:TP=-1.5 -ar 48000 build/mix_norm.wav
python3 render.py --stills 0,20,90 --out qa   # quick preview frames
./render_all.sh out_cap && ./encode.sh out_cap The_Keyhole.mp4
./render_all.sh out_nocap --nocap && ./encode.sh out_nocap The_Keyhole_no_captions.mp4
```

## Where to change things

- **Lines, pauses, voices**: `script.py`. `[p0.6]` inserts a pause and `[B:word]` bleeps a word. `VOICES` maps characters to Kokoro voices and speeds.
- **Acting and cameras**: `scenes.py`. Each `actor.at(time, duration, expr=..., look=..., armR=...)` is an acting beat keyed to line/marker times.
- **Character looks and expressions**: `rig.py` (`EXPR` presets, `make_cast()`).
- **Music**: `music.py`, one function per cue.
