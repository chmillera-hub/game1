# ANGER

A 4:55 portrait (720×1280, 24 fps) animated short, told by a narrator. ANGER is a huge, grim, armored warrior. He hacks his
way through a cave, bursts through a locked door, loses his torch in the dark, falls down a shaft and saves
himself by dragging his sword down the wall. At the bottom he meets a crawler with glowing eyes, an unseen
hermit who knocks it out and eats it, and the hermit's big, sassy, drooling friend. Played completely
straight, then deadpan: "Well… I guess I'll die then."

A deep, old storyteller narrates the action as it happens ("Anger did not believe in locked doors." …
*BOOM* … "Only in open ones."), so every line pairs with something you see. Narration captions are set
in warm italics; dialogue captions in white.

**Final video:** [`out/anger.mp4`](out/anger.mp4): H.264 High + AAC, under 15 MB, with burned-in subtitles.
[`out/anger.srt`](out/anger.srt) has the same captions for platforms that accept caption uploads.

Everything is generated by code:
- **Voices:** Kokoro TTS (Anger: `am_onyx`, the hermit: `am_santa`, the narrator: `bm_george` pitched down
  3 semitones), with lip-sync. Lines are spoken sentence by sentence with pauses (`|` in the TTS text) and
  coloured per line (`MOOD` in `script_data.py`: a pained breath and a shaky voice when Anger is hurt, a sigh,
  a gasp). The hermit's long laugh is stitched from single laugh syllables.
- **Music:** an orchestral score composed as MIDI and rendered with FluidSynth, plus a few numpy-synthesized
  layers (heartbeat, drones, booms).
- **Sound:** 50 synthesized sound effects.
- **Picture:** skia-python vector animation, using a darkness/light-map system for the torch-lit cave.

`BIBLE.md` is the production bible: story, character designs, shot list and continuity.

## Rebuilding

Requirements: Python 3 with `skia-python numpy scipy pillow soundfile mido pretty_midi pyloudnorm
kokoro-onnx faster-whisper`, plus `ffmpeg`, `fluidsynth`, `musescore-general-soundfont` and `espeak-ng`.
The Kokoro model files `kokoro-v1.0.onnx` and `voices-v1.0.bin` go in `/home/user/models` (see `config.py`).

```
python3 build.py              # anything missing, then mix + render + encode -> out/
python3 build.py --force      # also regenerate voices, music and SFX
python3 build.py audio        # audio only (tts, timeline, music, sfx, scene-locked sfx, mix)
python3 build.py encode       # re-encode only (from build/video_master.mkv + build/mix.wav)
python3 -m anim.preview sheet out.png 0 33 120 224   # contact sheet of any moments
```

## Where to change things

| Want to change… | Edit |
|---|---|
| Dialogue, narration, voices, pacing, beat timing | `script_data.py` (`LINES`, `VOICES`, `MOOD`, `SEQ`) |
| A scene's staging, camera, acting | `anim/scenes/s1.py` … `s6.py` |
| How Anger / the crawler / the friend look | `anim/char_anger.py`, `anim/char_crawler.py`, `anim/char_friend.py` |
| Tunnel, door, cavern, shaft, depths | `anim/env.py` |
| Darkness and light (torch, fungi, sparks) | `anim/light.py` |
| Title, dust, debris, sparks, splash, drips, saliva | `anim/fx.py` |
| Music | `audio/music.py` (+ `audio/music_lib.py`) |
| Sound effects / mix levels | `audio/sfx.py`, `audio/mix.py` |
| Subtitle style / position | `anim/subtitles.py` |
| File size / encode settings | `build.py` (`TARGET_BYTES`, `AUDIO_KBPS`, `encode()`) |

Scenes reference times by beat name, so changing a line or a pause in `script_data.py` re-times
everything that depends on it automatically; the music reads its sync hits from the timeline too, so after
a timing change re-render it (`python3 audio/music.py`, then `python3 build/tests/music/check_hits.py`).
`line_at` / `line_end_at` events lay narration over the action without moving any beat.
