# Psalm 22 — soundtrack (score, sound design, mix)

Everything is generated by code from `timeline.json` + `phrases.json`; no seconds are hard-coded.
Re-run the three scripts after the narration or the timeline changes.

## Regenerate

```bash
# one-time setup (already done on this machine)
apt-get install -y fluidsynth                       # renderer (2.3.x)
/opt/venv/bin/pip install mido pyloudnorm matplotlib
mkdir -p /opt/assets/soundfonts && curl -o /opt/assets/soundfonts/MuseScore_General.sf2 \
  https://ftp.osuosl.org/pub/musescore/soundfont/MuseScore_General/MuseScore_General.sf2   # MIT, 215 MB

# after audio/tts.py + timeline.py
/opt/venv/bin/python psalm22/audio/music.py     # ~1.5-3.5 min  -> $WORK/audio/music.wav + stems
/opt/venv/bin/python psalm22/audio/sfx.py       # ~2-4 min      -> $WORK/audio/sfx.wav + stems (+~4 min once for the TTS crowd cache)
/opt/venv/bin/python psalm22/audio/mix.py       # ~2 min        -> $WORK/audio/mix.wav, mix.m4a, report
/opt/venv/bin/python psalm22/audio/mix.py --whisper   # optional: + transcription WER check (+4 min)
```
`music.py --check` only builds the arrangement and prints the section grid and any melody/harmony
clash warnings (no rendering). `TIMELINE=… PHRASES=…` override the input files (used to test that a
re-timed film — every block stretched by ±10 % — still arranges cleanly and all cues land in their shots). Peak RAM of the mix is ~3 GB; music/sfx use less.
If `MuseScore_General.sf2` is missing, music.py falls back to `/usr/share/sounds/sf2/FluidR3_GM.sf2`
(apt `fluid-soundfont-gm`), with a different (thinner) sound. Override with `SF2=/path/file.sf2`.

For the compositor: the mix is sample-aligned with `narration.wav` (t = 0 is frame 1). Use
`ffmpeg -i video.mp4 -i $WORK/audio/mix.m4a -map 0:v -map 1:a -c copy -shortest out.mp4`.
If you re-encode from `mix.wav` instead, use ≥ 96 kbps: ffmpeg's AAC adds ~1 dB of peak overshoot
at 96k, ~1.3 dB at 80k and up to ~3 dB at 64k (mix.wav is mastered to −2.0 dBTP for this reason).

## Code layout

| File | Role |
|---|---|
| `audio/dsp.py` | shared helpers: timing loader, RBJ filters, synthetic hall IR + convolution reverb, BS.1770 loudness (pyloudnorm), 4×-oversampled true-peak meter, look-ahead true-peak limiter |
| `audio/music.py` | `SCORE` (hand-written sketch per block) → `Arranger` (voice-leading, layers, expression) → MIDI → FluidSynth → reverb/balance |
| `audio/sfx.py` | procedural generators + `AMB` (ambience per shot), `FX` (spot cues), automatic transitions |
| `audio/mix.py` | narration chain, phrase-driven ducking, master, analysis, AAC export |

### Score (`music.py`)
* One `SCORE` entry per text block (`intro`, `b01`…`b20`, `outro`). `b20` ends — and `outro`
  starts — exactly at the start of the last phrase, so the climax lands on **“He has done it!”**.
  Each entry has `N` beats which are stretched to the block length from `timeline.json`
  (tempo 54–66 bpm; a warning is printed if a re-timed block leaves 0.7–1.4 s/beat).
* `chords`: `"Dm:4 Gm/D:2 …"` (beats). Upper strings, choir, horns and tremolo are voiced by a
  small search (all essential chord tones, no voice crossing, ≤ octave spacing, minimal motion,
  parallel-fifth/octave penalty, no doubled thirds), steered by an optional `top` register plan
  (e.g. the rising strings of b14). Common tones are tied, so pedals sustain.
* `layers`: gain or `(gain, from_beat, to_beat)` windows for `bass, celli, upper, top8, trem,
  aahs, oohs, horns, harp, pizz`. `dyn`: intensity curve 0…1 (drives CC2 dynamics of the
  MuseScore "Expr." presets + velocities). Breakpoints may be anchors: `("shot", "s12b", 0)`,
  `("hammer", 0)`.
* `mel`: solo lines `(instrument, start_beat, "A4:1.75~ Bb4:.25 …", gain)`; `~` = duduk-style
  scoop (pitch bend), `X/Y` = grace note. Lines may spill into the next block (block-end "sighs").
  The arranger warns when a melody note sits > ½ beat on a chord it doesn't belong to.
* `perc`: `boom`, `hit`, `roll`, `heart` (lub-dub at a given bpm), `crash`.
* Instruments: MuseScore_General section strings (Basses/Celli/Violas/Violins Slow Expr.), solo
  Cello Expr., English horn Expr. as the duduk-like lament voice (scoops + vibrato), Oboe, Choir
  Aahs/Voice Oohs, French horns, Trombone, Trumpet, Timpani, Concert Bass Drum, Orchestra-kit
  cymbal, Harp, Celesta. Rendering: FluidSynth (internal reverb/chorus off) → per-stem high-pass,
  −2.5 dB shelf at 9 kHz, synthetic hall IR (RT60 2.6–3.4 s), balance on active RMS.
* Key plan: D minor with Hijaz/Phrygian-dominant colour (melodic A–Bb–C#, bII Eb over the D
  pedal, A major dominant) through b13; b14 turns via a rising bass (Bb–C–D–E–F–G…) onto A7;
  b15 lands in D major; b20 lifts with bVI–bVII (Bb–C) into the D-major climax; plagal G/D “amen”.

### Sound design (`sfx.py`)
All synthesised (deterministic seeds): wind with gusts/howl/dust, distant thunder, crickets,
cicadas, dawn birds, water-wall roar, fire/torches/oil lamps/candle, room tone, footsteps (mob,
seabed, soldiers), modal-synthesis metal (hammer on iron, sword, gold clinks), bone dice, bubbles
(water pour), stick-slip wood creak, earthquake + rolling stone, sand disintegration, animal
vocalisations (formant-filtered harmonic source with jitter/roughness: lion growl/roar, bull
bellow/snorts, dog growls/snarls/yelps), hooves (gait patterns circling in the stereo field).
Crowd murmur/jeers (s06, s13, s16a, s17a) are Kokoro TTS voices (≠ narrator) reading transliterated
Hebrew taunts ("Hoshia et atzmekha!" = "Save yourself!"), layered, pitched and filtered so they
read as an ancient crowd and never compete with the English narration (cached in `audio/sfx_cache`).

* `AMB[layer]["shots"] = {shot_id: dB}` → per-shot ambience levels with cross-fades.
* `FX = [(shot, anchor, offset, kind, dB, pan, stem)]`, anchor = `"start"|"end"|fraction|("ph", k, "start"|"end")`
  (k-th narration phrase of the shot's block). The hammer is `("ph", 1, "start") + HAMMER_OFFSET`
  (0.32 s, shared with the music impact) — change that one constant if the s12b render puts the
  impact elsewhere.
* Transitions come from `transition_in`: `flash` → 2.2 s rising whoosh + bright bloom + sub thump;
  `fade_black` → falling whoosh + low boom; `dissolve` → faint air swell; plus a final 4 s swell into
  “He has done it!” and a long bloom under the end title.

### Mix (`mix.py`)
1. Narration (timing untouched): HPF 75 Hz, −1.5 dB @ 220 Hz, +2 dB @ 3.2 kHz, −2 dB @ 6 kHz
   (the TTS voice's sibilance peak), split-band de-esser (4.8–10 kHz), 2.2:1 compressor, look-ahead peak limiter (loudness + 13 dB),
   small room reverb (RT 0.55 s, 7 % wet).
2. Music bus (HPF 30 Hz): slow leveler (±4 dB, ratio 0.35), gain so its loudest 3 s ≈ voice + 1 dB (speech band).
   SFX bus (HPF 38 Hz): ambience integrated loudness = voice − 21 LU.
3. Ducking from `phrases.json`: phrases closer than 1 s form one speech run; 0.30 s cosine attack
   before, 0.55 s release after. Depth is computed **per phrase** = min(base, voice − margin − bus),
   where bus = loudest 1 s window, measured in the 200 Hz–5 kHz speech band: music base −6 dB /
   margin 12.5 dB (b15: 10 dB, b20: 12 → 8.5 dB so the build is heard, last phrase 6 dB so the
   climax lands on it), + a −4 dB @ 2.6 kHz dynamic carve; ambience −4/15 dB, spot FX −1.5/9.5 dB,
   transitions −3/10 dB.
4. Master: 15.5 kHz low-pass (AAC safety), gain to −14 LUFS, 4×-oversampled look-ahead limiter,
   ceiling −2.0 dBTP (iterated so the result is −14.0 LUFS).

## Known limitations
* Rendered from a General-MIDI-class soundfont: convincing orchestral colour in a mix, but
  not sample-library realism (legato transitions, solo-string expressiveness are limited).
  The "duduk" is an English horn with scoops/vibrato.
* Animal sounds are synthetic (formant models). Under music and narration they read as
  growls/roars/snorts, but they are the least realistic element; replace with CC0 recordings via
  the `make_fx` hooks if available.
* Visual sync points that are not in the timeline (hammer impact, sword drop, stone, roar) are
  estimated from phrase/shot anchors; adjust the offsets in `FX` / `HAMMER_OFFSET` once the
  renders exist.
