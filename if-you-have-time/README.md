# If You Have Time

A 3:28 portrait (720×1280, 24 fps) animated short: a tired crew member casually asks the ship's
android to write her a symphony "if you ever have time"… and he does, instantly. She's quietly moved
while ship life carries on around her: a passing cadet mutters "cool music," and nobody makes a big
deal of it. Then Quill casually plays her four more versions.

**Final video:** [`out/if_you_have_time.mp4`](out/if_you_have_time.mp4): H.264 High + AAC, 13.97 MB,
with burned-in subtitles. [`out/if_you_have_time.srt`](out/if_you_have_time.srt) has the same captions
for platforms that accept caption uploads.

Everything is generated by code: Kokoro TTS voices with lip-sync, music composed as MIDI and
rendered with FluidSynth plus a few numpy-synthesized instruments (kazoo, chiptune, theremin),
synthesized sound effects, and skia-python vector animation. `BIBLE.md` is the production bible:
story, character designs, shot list and continuity.

## Rebuilding

Requirements: Python 3 with `skia-python numpy scipy pillow soundfile mido pretty_midi pyloudnorm
kokoro-onnx faster-whisper`, plus `ffmpeg`, `fluidsynth`, `musescore-general-soundfont`,
`fluid-soundfont-gm` and `espeak-ng`. The Kokoro model files `kokoro-v1.0.onnx` and `voices-v1.0.bin`
go in `/home/user/models` (see `config.py`).

```
python3 build.py              # anything missing, then mix + render + encode -> out/
python3 build.py --force      # also regenerate voices, music and SFX
python3 build.py audio        # audio only (tts, timeline, music, sfx, mix)
python3 build.py encode       # re-encode only (from build/video_master.mkv + build/mix.wav)
python3 -m anim.preview sheet out.png 20 43.3 112   # contact sheet of any moments
```

## Where to change things

| Want to change… | Edit |
|---|---|
| Dialogue, voices, pacing, beat timing | `script_data.py` (`LINES`, `VOICES`, `SEQ`) |
| A scene's staging, camera, acting | `anim/scenes/s0.py` … `s5.py` |
| How Rae / Quill / the cadet look | `anim/char_rae.py`, `anim/char_quill.py`, `anim/char_cadet.py` |
| Ship, lounge, space | `anim/env.py` |
| Ribbons, memory bubbles, holo-cards, titles | `anim/fx.py` |
| Music | `audio/music.py` (`THEME_A` and the `compose_*` functions) |
| Sound effects / mix levels | `audio/sfx.py`, `audio/mix.py` |
| Subtitle style / position | `anim/subtitles.py` |
| File size / encode settings | `build.py` (`TARGET_BYTES`, `AUDIO_KBPS`, `encode()`) |

Scenes reference times by beat name, so changing a line or a pause in `script_data.py` re-times
everything that depends on it automatically.
