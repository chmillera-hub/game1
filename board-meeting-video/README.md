# Kingdom of Heaven, Inc.

A 4:52 portrait (1080×1920, 30 fps) animated short. A creator stuck on the
"just make a new account" hamster wheel wonders how someone with a heart like
Jesus would fare under the same system. That reflection plays out as a
creator account review at Mammon Media. The executives use 2026 platform-speak
(engagement, monetization funnels, brand safety, rage bait). Jesus answers from
his own teachings, gets his account suppressed, and leaves a seed behind.

Final video: [`kingdom_of_heaven_inc.mp4`](kingdom_of_heaven_inc.mp4)

Everything is generated by code. Voices come from Piper neural TTS and are
checked with Whisper. The music and sound effects are synthesized in NumPy,
and the vector art is drawn with Skia. There are no stock assets, so the
whole thing is yours to use and change.

## Files

| File | What it does |
| --- | --- |
| `script.py` | Screenplay as data: lines, voices, pauses. Edit this to change dialogue. |
| `tts.py` | Synthesizes each line (best of 5 takes, scored by Whisper), builds `timeline.json` with word timings |
| `common.py` | Drawing helpers, easing, noise, timeline access |
| `characters.py` | Faces (eyes, lids, brows, lip-sync mouths, expressions), bodies, arms |
| `cast.py` | Character looks |
| `opening.py` | Act 1: bedroom, phone, hamster wheel, growth engine, money bag |
| `boardroom.py` | Act 2: the account review (camera shots, slides, expressions, gaze, exit) |
| `epilogue.py` | Act 3: seed, time-lapse tree, birds, dawn, end card |
| `film.py` | Scene switching, title card, captions |
| `audio.py` | Score, SFX, dialogue mix, two-pass loudness normalization (−14 LUFS) |
| `render.py` | Parallel frame rendering |
| `encode.sh` | Final H.264/AAC encode |
| `preview.py` | Render single frames to PNG for checking |

## Rebuild

```bash
pip install piper-tts faster-whisper skia-python scipy numpy
# Piper voices listed in script.py go in $VOICE_DIR (default /tmp/claude-0/voices)
export BUILD=/path/to/build
python3 tts.py        # voices + timeline
python3 audio.py      # music + mix
python3 render.py 4   # frames (4 workers)
./encode.sh 24        # final mp4
```

To change a line, edit `script.py` and rerun everything from `tts.py`. Only
the changed lines are re-synthesized, and every visual cue is anchored to line
and word timings, so the animation re-times itself.
