# Fonts

Vendored from Google Fonts (latin subset, variable woff2) so the film renders
identically offline. All three families are licensed under the SIL Open Font
License 1.1 (https://openfontlicense.org).

- Cormorant Garamond — Christian Thalmann (Catharsis Fonts) — narration & titles
- Nunito — Vernon Adams, Cyreal, Jacques Le Bailly — speech bubbles & UI
- Caveat — Impallari Type — the inner voice / handwriting
