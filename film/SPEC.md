# THE STONE AND THE BREAD — Production Spec

This is the contract every agent works from. The script itself is in `SCRIPT.md` (verbatim from the
user). This file adds the technical pipeline, the art direction, and a **beat sheet** with target
timings. When the two disagree, the script wins on *content*; this spec wins on *how it is built*.

## 1. Deliverable

- `film/out/the_stone_and_the_bread.mp4`: 1920x1080, 24 fps, H.264 (yuv420p, CRF ~20, `-preset slow`),
  AAC 48 kHz stereo 192 kbps, burned-in captions. Target length: **3:30** (8 scenes = 200 s + 10 s end card).
- The whole film is generated by code in `film/` and can be rebuilt with `python3 film/make.py`.
- Everything under `film/build/` is a scratch/intermediate area (git-ignored): voices, wavs, frames,
  per-scene mp4s, previews.

## 2. Toolchain (already installed in this container)

- Python 3, `numpy`, `Pillow`, `cairocffi` (`import cairocffi as cairo`) on system cairo 1.18:
  antialiased vector drawing, gradients, paths, toy text API with fontconfig fonts.
- `ffmpeg` (with libass, drawtext).
- `piper-tts` (`python3 -m piper` / `from piper import PiperVoice`), voices downloading into
  `film/build/voices/*.onnx` (+ `.onnx.json`).
- Fonts installed in fontconfig (and committed under `film/assets/fonts/`, all OFL):
  `Inter` (UI/captions), `Caveat` and `Patrick Hand` (handwriting), `Permanent Marker` (signs, stamp),
  `Bebas Neue` and `Oswald` (signage), `Cormorant Garamond` (+ Italic) (end card, elegant serif).
  With cairo's toy API: `cr.select_font_face("Caveat", cairo.FONT_SLANT_NORMAL, cairo.FONT_WEIGHT_NORMAL)`.
- 4 CPUs, no GPU. Keep a frame's render time under ~150 ms at 1920x1080.

## 3. Code layout and contracts

```
film/
  SPEC.md  SCRIPT.md  README.md
  make.py                 # one command: tts -> sfx/music/mix -> render scenes -> assemble
  timeline.json           # GENERATED by film/audio/tts.py, committed. Single source of timing truth.
  lib/                    # shared visual library (package: `from film.lib import ...`)
    __init__.py
    core.py               # canvas/surface helpers, colors, easing, camera, noise, text helpers
    characters.py         # the character rig: Man, Old Woman, generic Person (extras), Pigeon
    props.py              # recurring props: pharmacy bag, coloring book, phone, bread loaf, bench, streetlight
    timeline.py           # loads timeline.json; line()/beat() lookups; talk(t, speaker) mouth amount
  scenes/
    s1_laundromat.py s2_pharmacy.py s3_phone.py s4_bar.py s5_crowd.py
    s6_bench.py s7_bread.py s8_close.py s9_endcard.py
  audio/
    tts.py                # casts voices, synthesizes every line, writes timeline.json + line wavs
    sfx.py music.py       # procedural ambience, foley, hold-music, score
    mix.py                # builds film/build/audio/mix.wav (full 210 s, 48 kHz stereo)
  render.py               # renders scenes to film/build/video/sN.mp4 (and --preview keyframes PNG)
  assemble.py             # concat scenes + mix.wav + captions (ASS) -> film/out/the_stone_and_the_bread.mp4
  assets/fonts/
  build/  (ignored)
  out/    the final mp4 (committed)
```

Run everything from the repo root (`/home/user/game1`) so `film` is importable as a package
(`python3 -m film.render ...` or `python3 film/render.py` with a `sys.path` insert — pick one in
render.py and keep it consistent; scenes import `from film.lib import core, characters, props, timeline`).

### Scene module contract

Each `film/scenes/sN_*.py` defines:

```python
SCENE = 3                      # scene number (1..9)
def setup():                   # optional, called once; return any precomputed state (or None)
    ...
def draw(cr, t, state):        # draw ONE frame. cr = cairo.Context on a 1920x1080 ARGB32 surface,
    ...                        # t = LOCAL scene time in seconds (0 <= t < duration). Must fully paint
                               # the frame (no reliance on previous frames). Deterministic: seed any
                               # randomness (e.g. random.Random(1234)), never use wall-clock time.
```

Scene duration is `timeline.scene(SCENE).duration` (from timeline.json), never hard-coded elsewhere.
All per-line timing comes from `timeline.line(id)` (`.start`, `.end` local to the scene). Visual
beats come from `timeline.beat(id)` (local seconds). If you need an extra beat, define it as a
constant in your scene file relative to existing lines/beats.

### render.py

- `python3 film/render.py --scene 3` → renders `film/build/video/s3.mp4` (video only, exact frame count
  `round(duration*24)`), piping raw BGRA frames (`cairo.FORMAT_ARGB32` on little-endian = `bgra`)
  into ffmpeg (`-f rawvideo -pix_fmt bgra -s 1920x1080 -r 24 -i -`, out `-c:v libx264 -crf 18 -pix_fmt yuv420p`).
- `python3 film/render.py --scene 3 --preview [--times 0,2.5,10]` → writes PNG keyframes to
  `film/build/preview/s3_t002.50.png` (default: one frame every 2 s plus every line start + 0.3 s and every beat).
  Also `--contact` writes a single contact-sheet PNG `film/build/preview/s3_contact.png` (grid of
  downscaled keyframes with timestamps) — the fastest way for a reviewer to look at a whole scene.
- `python3 film/render.py --all [--jobs 4]` renders every scene in parallel processes.
- `python3 film/render.py --sheet` renders `film/build/preview/character_sheet.png` (all characters in
  all poses/expressions) — the core library's visual test.

### Captions

Burned in by `assemble.py` from `timeline.json` as an ASS subtitle track: Inter SemiBold ~46 px,
white with a soft dark outline/shadow, bottom-center, 80 px margin. Each line shows from its start
to its end + 0.25 s. Rules: lines with `"caption": false` are not captioned (the PHONE VOICE lines —
scene 3 shows them as on-screen floating text instead). Voiceover lines (`"vo": true`) are italic.
The drowned-out line in scene 4 is captioned but fades out as the music swells (use ASS `\fad` / alpha
animation). Scene art must keep the bottom ~180 px free of critical detail (captions sit there).
No speaker labels.

## 4. Art direction

**Style:** flat 2D vector illustration, "quiet indie animated short". Soft geometric shapes, no
outlines (or very thin darker outlines on characters only), gentle gradients for light, subtle grain
(a cheap static/precomputed noise overlay at 3–5 % opacity) and a soft vignette. Limited palettes per
scene; light tells the emotional story:

| Scene | Palette / light | Mood |
|---|---|---|
| 1 Laundromat | sickly cool fluorescent (cyan/teal/green-grey), black night windows | isolated, hum |
| 2 Pharmacy | over-bright clinical white/mint, hard shadows | sterile, kind but useless |
| 3 Phone | deep navy rain, sodium-orange streetlight reflections on wet asphalt | lonely, drifting |
| 4 Bar | hot magenta/amber string lights, saturated, slightly blown out | loud, fake |
| 5 Crowd | evening grey-blue concrete, phone-screen glows | cold, voyeur |
| 6 Bench | dusk: violet → peach sky, long shadows, first warmth | tender, funny |
| 7 Bread | golden hour fading into blue hour; warm lamplight comes on | warmth spreading |
| 8 Close | dark blue night, ONE warm streetlight pool over the benches; distant small cool city signs | hope |
| 9 End card | near-black warm charcoal, cream text | reverent |

**Camera:** gentle, slow moves only (push-ins, pans, pull-backs with ease-in-out). Hard cuts between
scenes; scene 1 fades in from black over ~1 s; scene 8 fades to black at its end; the end card fades
in from and out to black. Inside a scene, an "insert" close-up (note, stamp, sign) may be done as a
hard cut or a quick push.

**Recurring visual motifs:** the Man's stuff from the pharmacy (white paper bag with a green cross,
the coloring book "MINDFUL COLORING FOR ADULTS" with a mandala cover) travels with him from scene 2
to scene 6. The SMILE stamp is still faintly visible on the back of his hand in scenes 5–7 (subtle).
Screens/phones emit cold blue light; bread and the final streetlight emit warm light.

### Characters (all drawn by `film/lib/characters.py`, never re-invented in scene files)

- **The Man** (protagonist, mid-30s): tall and slim, slightly stooped shoulders. Medium-tan skin
  (#C68E6A-ish), short messy dark-brown hair, light stubble shadow, tired eyes (simple dark eyes with
  a heavy upper lid line), expressive eyebrows. Wears a long **charcoal-navy coat** (#2F3A4F) over a
  **mustard sweater** (#C9A13B), dark grey trousers, brown boots. The mustard is the one warm color he
  carries through the cold scenes.
- **The Old Woman**: small, round, slightly hunched; silver-white hair in a bun, round glasses,
  rosy cheeks, warm brown skin or fair — pick one and keep it (#E2B79A-ish suggested). Lavender
  cardigan (#9B8BB8), long forest-green skirt, cream scarf, a cloth tote with a round loaf of
  crusty bread (golden-brown, scored top).
- **Extras** via a generic `Person` with parameters (skin, hair style/color, top/bottom colors,
  height/build, accessories: earbuds, glasses, cap, hoodie hood, hi-vis vest, apron/white coat,
  delivery bag, backpack, phone-in-hand):
  laundromat woman (earbuds, oversized hoodie, phone), pharmacist (white coat, glasses, kind, hair in
  a low ponytail), bouncer (very broad, black tee, shaved head, beard), bar crowd (varied), two fighters
  (one in red jacket, one in grey hoodie), street crowd (varied, phones up), teenager (red hoodie,
  backpack, headphones around neck), delivery driver (brown/olive uniform, cap, insulated bag, tired),
  worker (orange hi-vis vest, hard hat in hand or boots, dusty).
- **Pigeons**: plump grey, iridescent green-purple neck, coral feet; can peck, look left/right
  (head swivel is a running gag in scene 6), hop, flap.

**Rig requirements:** each character draws at an anchor (feet center or seat point), with a scale,
facing (left / right / front-ish 3/4), and pose parameters: stand, walk cycle (phase), sit (on a
bench/chair height), lean, head turn and tilt, eye direction, blink (auto from t), eyebrow mood,
mouth (closed / talking amount 0..1 / smile / laugh / frown), arms with simple 2-segment angles (or
named gestures: hand_to_ear_phone, hand_out_offer, hold_item, arms_crossed, hands_in_pockets,
tap_point, raise_phone_film, hug). Talking mouth amount comes from `timeline.talk(t_global_or_local, speaker)`
driven by the TTS envelope so lips follow the actual audio.

## 5. Audio direction

- Dialogue: Piper neural TTS, one consistent voice per character (cast in `audio/tts.py`, documented
  in timeline.json `"cast"`). Man: warm, low-key male. Old Woman: warm, older-sounding female, slower
  pace. Pharmacist: kind female. Phone voice: crisp corporate female, telephone band-limited.
  Bouncer: deep male. Crowd person: young voice, disgusted. Man's voiceover in scene 8: same voice,
  slower, close, a touch of room reverb.
- Ambience/foley, all procedural (numpy) or TTS-derived (crowd walla/laughs/cheers can be built from
  many layered LibriTTS-R speakers at low level, pitch/time-jittered):
  S1 dryer drum rumble + tumbling thumps + fluorescent hum; S2 fluorescent buzz, faint muzak,
  item "thunk"s on the counter, register beeps; S3 rain on pavement, distant traffic hiss, the
  **hold music: the same four notes over and over** (thin electric piano through a phone band-pass);
  S4 thumping bass music through a wall, then loud inside, synchronized crowd laughter at one level,
  stamp thunk, music SWELLS to drown his line, door closes → muffled; S5 street, cheering, phones,
  sudden silence at the hug; S6 dusk park: soft birds, pigeon coos, wings, distant city, his laugh;
  S7 pigeons flutter, bread tearing, bench scrape, warm murmuring that grows; S8 night crickets, soft
  conversation murmur, voiceover; S9 silence + final chord.
- **Score:** a gentle piano (additive/physical-ish synthesis: decaying partials, slight detune,
  soft hammer noise, sustain-pedal tail) that enters quietly at the laugh in scene 6 and blooms in
  scenes 7–8. Its main theme is **the same four notes as the hold music**, but slow, warm, and
  harmonized — the stone turned into bread. Ends on a held chord over the end card.
- Mix: dialogue always intelligible (duck ambience/music −8 to −12 dB under lines, except the
  intentionally drowned line in S4). Peak ≤ −1 dBFS, integrated loudness about −16 LUFS.

## 6. Beat sheet (target LOCAL times in seconds; `tts.py` writes the real times into timeline.json)

Scene start times (global): S1 0, S2 25, S3 50, S4 70, S5 95, S6 120, S7 150, S8 180, S9 200, end 210.
Scene durations are fixed (25, 25, 20, 25, 25, 30, 30, 20, 10). A line's target start may move by
up to ±1.0 s to fit its real TTS length; a line must never overlap the next line of the same scene
and must end ≥0.6 s before the scene ends.

Line ids use `sN_lK`; beat ids use `sN_<name>`.

### S1 — The laundromat (dur 25)
- `s1_fadein` 0.0–1.0: fade from black. Already in motion: wide shot, rows of front-loading dryers
  with clothes tumbling behind round glass doors, fluorescent tubes, linoleum, black night windows.
  Man alone on an orange plastic chair (left-center) watching his dryer. Woman on a chair to the right,
  earbuds in, face lit by her phone. Slow push-in throughout 0–8.
- `s1_glance` 5.5: he glances at her; `s1_lean` 7.0: he leans over, mouth opens to speak (no audio).
- `s1_tap` 8.3: without looking up, she reaches back and taps a laminated sign on the wall:
  **SELF-SERVICE** (camera pushes/cuts to the sign 8.3–11.0; her finger taps twice).
- `s1_l1` ~11.8 MAN: "Self-service."
- `s1_lookaround` 13.5–18.0: he looks around at the spinning machines (head turns; camera drifts
  across the row; each dryer spins someone's laundry with no one there).
- `s1_l2` ~18.5 MAN: "That's the whole city, isn't it."
- 21–25: hold on him small among the spinning dryers.

### S2 — The pharmacy (dur 25)
- 0.0: bright fluorescent pharmacy counter; shelves behind; "PHARMACY" sign with a green cross.
  The Man at the counter, pharmacist behind it.
- `s2_slide` 1.5: he slides a folded note across the counter.
- `s2_note` 3.0–6.0: insert close-up of the note, handwriting: **"Something for loneliness?"**
- `s2_nod` 6.5: she reads it, nods kindly.
- `s2_items` 8.0–16.5: she walks the aisles and stacks items on the counter one by one (each a
  thunk): `s2_item1` 9.0 sleep aid ("SLEEP AID" box/bottle), `s2_item2` 11.0 vitamins, `s2_item3`
  13.0 stress-relief candle ("CALM" jar candle), `s2_item4` 15.0 coloring book for adults
  ("MINDFUL COLORING FOR ADULTS", mandala cover). The pile grows absurdly neat and tall.
- `s2_stare` 16.5: he stares at the pile.
- `s2_l1` ~17.0 PHARMACIST: "Try these. Lots of people swear by them."
- `s2_l2` ~20.3 MAN: "Do any of them talk back?"
- `s2_pause` 22.3: she pauses (a held beat, smile freezes slightly)…
- `s2_ring` 23.3: …then rings him up anyway (register beep-beep, receipt curls out). 

### S3 — The phone menu (dur 20)
- 0.0: rainy street at night, wet reflective asphalt, streetlights, shop fronts closed. He walks
  (side view, walk cycle, background parallax), phone to his ear, pharmacy bag in the other hand.
  Floating text in a clean phone-UI style appears word-by-word as the PHONE VOICE speaks:
- `s3_l1` ~1.0 PHONE VOICE: "For billing, press one."
- `s3_l2` ~3.6 PHONE VOICE: "For a new account, press two."
- `s3_l3` ~6.6 PHONE VOICE: "For loneliness… please hold."  (the word "loneliness" lands with a beat)
- `s3_hold` ~10.0–20.0: hold music — the same four notes, over and over (visual: four floating music

- `s3_l4` ~14.3 MAN: "I've been on hold my whole life."
- 17–20: he stands under a streetlight in the rain, the hold music looping.

### S4 — The bar door (dur 25)
- 0.0: exterior of a loud bar glowing with string lights; muffled bass; a bouncer at the door holding
  up a rubber stamp. The Man walks up.
- `s4_stamp` 3.0: bouncer stamps the back of his hand (thunk).
- `s4_smile` 3.6–6.0: insert close-up of the hand: the stamp reads **SMILE** in pink ink.
- `s4_inside` 6.3: inside: everyone under the string lights is laughing at exactly the same volume
  (synchronized laughing heads, identical open-mouth grins, a slightly uncanny rhythm).
- `s4_l1` ~10.0 MAN (drowned): "Can I tell you something? Lately I—"  ← he opens his mouth to say
  something real; `s4_swell` 10.8: the music swells and drowns him out (visual: speaker/bass waves,
  lights flare, his words get swallowed). Caption fades out.
- `s4_turn` 12.8: a few heads turn toward him. `s4_lookbouncer` 14.0: someone looks at the bouncer.
- `s4_l2` ~15.5 BOUNCER: "Keep it light, buddy."
- `s4_lookhand` 18.0: the man looks at the SMILE stamp on his hand.
- `s4_exit` 20.0–25.0: he quietly walks back out the door into the night; the door closes and the
  music muffles.

- `s5_stop` 8.5: one of the guys suddenly stops and drops his arms.
- `s5_hug` 9.6: he hugs the other.
- `s5_silence` 10.0: the crowd goes silent (audio cuts to near nothing).
- `s5_lower` 10.8–13.0: phones lower, one by one.

- `s5_l3` ~18.8 MAN: "But someone gets gentle, and everybody looks away."  (people turn away,

- `s6_book` 9.0: he takes out the coloring book from the pharmacy bag, flips through it (9.8–11.5),

- `s6_l2` ~16.0 MAN: "Candles. Vitamins. Yoga."
- `s6_l3` ~19.0 OLD WOMAN: "They told me to get a cat. I got the cat."

- `s6_l4` ~23.4 OLD WOMAN: "The cat sleeps through every story about my day."
- `s6_laugh` ~26.8: he laughs — the first time in the whole video (big honest laugh, head back,

- 2.5–6.5: they feed the pigeons together (more pigeons arrive).

  *"Which of you, if your son asks for bread, will give him a stone?"*  and  — Matthew 7:9
  Optionally a tiny line illustration: a grey stone and a broken loaf side by side. 8.5–10.0 fade out.

## 7. Quality bar

- Every beat in the script happens on screen, recognisably, in order. A viewer with the sound off
  should still follow the story; with captions off it should still be understandable by sound.
- Characters are on-model across scenes (same colors, proportions, clothes).
- No glitches: no flicker, no popping layers, no z-order errors, no text overflowing or cut off,
  nothing important under the caption band, no frozen frames, mouths move only when that character
  speaks.
- Deterministic and reproducible from `python3 film/make.py`.
