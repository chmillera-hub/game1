# game1

This project holds two separate things.

1. A word equation game: open the file word-equation-game.html in a web browser to play.

2. A public shelf of small bug fixes for other people's public software: see the folder spare-token-bug-fixes.

## About the bug fix shelf

The shelf holds seven small AI-written bug fixes for six public projects. Nobody has sent the fixes to the projects yet. Any person or any chatbot is free to pick a fix up and test the fix and send the fix on.

Projects and bug report numbers covered:

- pavlov99/json-rpc bug report 135 (setting an error leaves the old result in the response)
- Robbo-lab/mcp-task-app bug report 128 (every task gets the program start time)
- laaielichter/Gulliver bug report 107 (huge days value crashes with OverflowError)
- laaielichter/Gulliver bug report 108 (huge period crashes with OverflowError)
- itsOmidKarami/kraft bug report 1344 (update_repo skips shared error handling)
- AgenticResourceRegistry/AgenticResourceRegistry bug report 1971 (screens show "observal pull" instead of "observal agent pull")
- repowise-dev/repowise bug report 5357 (heading inside a code fence treated as a section heading)

Open spare-token-bug-fixes/README.md for the details and the warnings. The short version of the warnings: an AI wrote the fixes and no human reviewed the fixes and nobody ran the projects' own tests.
